# User Flow

## 1. 전체 사용자 흐름

```
[회원가입/로그인]
       ↓
[홈 - 조직도 뷰] ←──────────────────────┐
       ↓                                  │
   ┌───┴───┐                              │
   ↓       ↓                              │
[팀 상세] [팀 생성]                        │
   ↓       ↓                              │
   ↓   [템플릿 선택]                       │
   ↓       ↓                              │
   ↓   [커스터마이즈]                      │
   ↓       ↓                              │
   ↓   [팀 생성 완료] ──→ 홈으로 ──────────┘
   ↓
[작업 요청]
   ↓
[옵션 선택 + 입력]
   ↓
[실행]
   ↓
[실시간 모니터링]
   ↓
[작업 완료]
   ↓
[결과물 미리보기]
   ↓
   ┌───┴───┐
   ↓       ↓
[수정 요청] [다운로드]
   ↓
[재모니터링] → [결과물 미리보기]
```

---

## 2. 시나리오별 상세 흐름

### 시나리오 1: 마케팅 콘텐츠 자동 생성

```
1. 로그인 → 홈 (조직도)
2. "마케팅 팀" 카드 클릭
3. 팀 상세 화면 - 에이전트 조직도 확인
4. "새 작업 요청" 클릭
5. 옵션 선택:
   - 입력 유형: YouTube URL
   - 출력 유형: [블로그, SNS, 뉴스레터] 체크
6. URL 입력 → "실행" 클릭
7. 실시간 모니터링:
   - 🟢 content_director: "영상 분석 중..." (20%)
   - 🟡 blog_writer: "대기 중"
   - 🟡 social_writer: "대기 중"
   - 🟡 email_writer: "대기 중"
   - (시간 경과)
   - ✅ content_director: "분석 완료"
   - 🟢 blog_writer: "블로그 초안 작성 중..." (45%)
   - 🟢 social_writer: "SNS 캡션 생성 중..." (30%)
   - 🟢 email_writer: "뉴스레터 작성 중..." (25%)
8. 모든 에이전트 완료 → "결과물 보기" 클릭
9. 결과물 미리보기:
   - 탭: [블로그] [SNS] [뉴스레터]
   - 각 탭에서 내용 확인
10. "이 부분 수정해줘" → 수정 요청 → 재생성
11. 만족 → 다운로드
```

### 시나리오 2: 새 팀 생성

```
1. 홈 → "새 팀 만들기" 클릭
2. 템플릿 선택 화면:
   - 마케팅 팀 / 재무 팀 / 전략기획실 / 교육 팀 / ...
3. "재무 팀" 선택
4. 커스터마이즈 화면:
   - 기본 에이전트: finance_director, ocr_extractor, xlsx_processor
   - 에이전트 추가: "보고서 생성기" 추가
   - 에이전트 삭제: "ocr_extractor" 불필요 시 삭제
   - 역할 수정: finance_director의 프롬프트 조정
5. "팀 생성" 클릭
6. 홈으로 돌아감 → 조직도에 새 팀 표시
```

### 시나리오 3: 작업 이력 확인

```
1. 사이드바 → "작업 이력" 클릭
2. 작업 이력 화면:
   - 필터: 팀별, 날짜별, 상태별
   - 목록: 최근 작업 리스트
3. 특정 작업 클릭 → 결과물 다시 확인
4. 필요 시 재다운로드
```

## 3. 네비게이션 구조

```
[사이드바]
├── 🏠 홈 (조직도)
├── 📋 작업 이력
├── ➕ 새 팀 만들기
├── ⚙️ 설정
└── 👤 프로필

[헤더]
├── 검색
├── 알림 (작업 완료 알림)
└── 프로필 메뉴
```
