# PRD (Product Requirements Document)

## MVP Capsule

1. 목표: AI 에이전트 팀을 통합 관리하고 작업을 자동화하는 웹 플랫폼
2. 페르소나: IT/개발 서비스 1인 사업자 (추후 SaaS 확장)
3. 핵심 기능: FEAT-1 멀티 에이전트 팀 관리, FEAT-2 원클릭 작업 요청, FEAT-3 실시간 진행 모니터링
4. 성공 지표 (노스스타): 주간 활성 작업 수 (Weekly Active Tasks)
5. 입력 지표: 팀 생성 수, 작업 요청 수
6. 비기능 요구: 실시간 WebSocket 연결 안정성 99.9%
7. Out-of-scope: 모바일 앱, 외부 서비스 직접 발행 (블로그/SNS 자동 포스팅)
8. Top 리스크: Claude API 비용 관리 및 rate limit
9. 완화/실험: API 사용량 모니터링 대시보드 + 팀별 비용 추적
10. 다음 단계: 마케팅 팀 에이전트 프리셋 구현

---

## 1. 제품 개요

### 1.1 비전
"1인 사업자가 AI 직원 팀을 보유하는 시대" - 마케팅, 재무, 전략기획 등 10개 부서의 AI 에이전트 팀을 하나의 플랫폼에서 관리하고, 원클릭으로 작업을 요청하며, 실시간으로 진행 상황을 모니터링하는 통합 플랫폼.

### 1.2 문제 정의
- 1인 사업자는 콘텐츠 제작, 서류 작업, 데이터 분석, 회계 관리를 모두 혼자 처리해야 함
- AI 에이전트를 활용하고 싶지만, 각각 별도로 관리해야 하는 불편함
- 에이전트 작업 과정을 실시간으로 확인할 수 없어 불안함
- 결과물의 품질 관리가 수동으로 이루어짐

### 1.3 솔루션
Claude API 기반 멀티 에이전트 팀을 웹 UI에서 통합 관리하는 플랫폼

---

## 2. 타겟 사용자

### 2.1 1차 타겟 (MVP)
- IT/개발 서비스 1인 사업자
- AI 도구 경험: 초급~중급 (Claude Code 정도 사용 경험)
- 니즈: 반복 업무 자동화, 시간 절약
- 페인 포인트: 콘텐츠/서류/분석/회계를 혼자 처리하는 부담

### 2.2 2차 타겟 (확장)
- 스타트업 (5인 이하)
- 프리랜서 그룹
- 소규모 에이전시

---

## 3. 핵심 기능

### FEAT-1: 멀티 에이전트 팀 관리 (핵심!)
- 팀 템플릿 선택 (마케팅, 재무, 전략기획, 교육, 이커머스 등)
- 템플릿 기반 팀 생성 후 완전 커스터마이즈 가능
- 에이전트 추가/제거/역할 수정
- 팀별 조직도 시각화
- 전체 회사 조직도 뷰 (홈 화면)

### FEAT-2: 원클릭 작업 요청
- 팀 선택 → 옵션 선택 → 입력 → 실행
- 팀별 맞춤 옵션 UI (마케팅: 콘텐츠 유형 선택 / 재무: 문서 유형 선택)
- 입력 형태: URL, 텍스트, 파일 업로드
- 작업 큐 관리

### FEAT-3: 실시간 진행 모니터링
- 에이전트별 상태 카드 (대기/작업중/완료)
- 진행률 퍼센테이지
- 실시간 로그 스트리밍
- WebSocket 기반 라이브 업데이트

### FEAT-4: 결과물 관리
- 결과물 미리보기
- 수정 요청 → 재생성
- 다운로드
- 작업 이력 조회

## 4. 유사 서비스 벤치마킹

| 서비스 | 장점 | 단점 | 우리의 차별점 |

## 5. 가설 vs 사실

| 항목 | 가설/사실 | 검증 방법 |
|------|----------|----------|
| 1인 사업자가 멀티 에이전트를 원함 | 가설 | MVP 출시 후 사용자 인터뷰 |
| 실시간 모니터링이 필수 | 가설 | A/B 테스트 (모니터링 ON/OFF) |
| 템플릿 기반이 직접 구성보다 선호됨 | 가설 | 사용 데이터 분석 |
| Claude API가 10개 팀 동시 운용 가능 | 가설 | 기술 검증 (rate limit 테스트) |
| SaaS 유료 전환율 5% 이상 | 가설 | 베타 테스트 |

## 7. MVP 정의

### Phase 1 (MVP)
- 로그인/회원가입
- 홈 (조직도 뷰)
- 마케팅 팀 프리셋 (1개 팀만)
- 작업 요청 → 실시간 모니터링 → 결과물 미리보기
- 기본 설정

### Phase 2
- 나머지 팀 프리셋 추가 (재무, 전략기획 등)
- 팀 커스터마이즈
- 작업 이력

### Phase 3 (SaaS)
- 구독 모델 (무료/프로/엔터프라이즈)
- 사용량 과금
- 멀티 유저 지원

## 8. 실패 시나리오 및 학습 목표

| 실패 시나리오 | 학습 목표 | 대응 |
|-------------|----------|------|

| 사용자 이탈 | UX 개선 포인트 발견 | 온보딩 개선, 템플릿 다양화 |
