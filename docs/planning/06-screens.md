# 06-screens: 화면 목록 및 구성

> 이 문서는 /screen-spec의 입력입니다.

---

## 화면 목록 요약

| # | 화면 | URL | 인증 필요 |
|---|------|-----|----------|
| 1 | 로그인 | /login | N |
| 2 | 회원가입 | /signup | N |
| 3 | 홈 (조직도 뷰) | /dashboard | Y |
| 4 | 팀 상세 | /teams/:id | Y |
| 5 | 작업 요청 | /teams/:id/tasks/new | Y |
| 6 | 실시간 모니터링 | /tasks/:id/monitor | Y |
| 7 | 결과물 미리보기 | /tasks/:id/results | Y |
| 8 | 팀 생성 | /teams/new | Y |
| 9 | 작업 이력 | /tasks/history | Y |
| 10 | 설정 | /settings | Y |

---

## 1. 로그인 화면 (/login)

- **진입**: 앱 시작, 비인증 접근 시 리다이렉트
- **요소**:
  - 이메일 입력
  - 비밀번호 입력
  - 로그인 버튼
  - "회원가입" 링크
  - 소셜 로그인 (Google)
- **이동**: 로그인 성공 → /dashboard

## 2. 회원가입 화면 (/signup)

- **진입**: 로그인 화면에서 링크
- **요소**:
  - 이메일, 비밀번호, 이름 입력
  - 회원가입 버튼
  - "이미 계정이 있어요" 링크
- **이동**: 가입 성공 → /dashboard

## 3. 홈 - 조직도 뷰 (/dashboard)

- **진입**: 로그인 후, 사이드바 "홈"
- **요소**:
  - 전체 팀 조직도 (인터랙티브, React Flow 기반)
  - 각 팀 = 노드 (클릭 가능)
  - 팀별 상태 표시 (활성/작업중/비활성)
  - 팀 간 연결선 (데이터 흐름 표시 가능)
  - "새 팀 만들기" 버튼
  - 상단: 오늘의 요약 (진행중 작업 수, 완료 작업 수)
- **액션**:
  - 팀 노드 클릭 → /teams/:id
  - "새 팀 만들기" → /teams/new
  - 줌 인/아웃, 패닝

## 4. 팀 상세 (/teams/:id)

- **진입**: 홈에서 팀 클릭
- **요소**:
  - 팀 이름, 설명
  - 팀 내부 에이전트 조직도 (계층별)
    - Orchestration 레이어
    - Research / Execution 레이어
    - Quality 레이어
  - 각 에이전트 노드: 이름, 역할, 모델, 상태
  - "새 작업 요청" 버튼
  - "팀 설정" 버튼
  - 최근 작업 3-5개 미니 리스트
- **액션**:
  - "새 작업 요청" → /teams/:id/tasks/new
  - 에이전트 노드 클릭 → 에이전트 상세 사이드 패널
  - "팀 설정" → 팀 편집 모달

## 5. 작업 요청 (/teams/:id/tasks/new)

- **진입**: 팀 상세 → "새 작업 요청"
- **요소**:
  - Step 1: 작업 유형/옵션 선택
    - 팀별 맞춤 옵션 (마케팅: 콘텐츠 유형, 재무: 문서 유형 등)
    - 체크박스/라디오 형태
  - Step 2: 입력
    - URL 입력 / 텍스트 입력 / 파일 업로드
    - 추가 지시사항 (선택)
  - Step 3: 확인 및 실행
    - 선택한 옵션 요약
    - "실행" 버튼
- **이동**: 실행 클릭 → /tasks/:id/monitor

## 6. 실시간 모니터링 (/tasks/:id/monitor)

- **진입**: 작업 요청 실행 후 자동 이동
- **요소**:
  - 상단: 작업 전체 진행률 바
  - 에이전트 상태 카드 그리드:
    - 각 카드: 에이전트 이름, 상태 아이콘(색상), 현재 작업 메시지, 개별 진행률
    - 상태: 🟢 작업중 / 🟡 대기중 / ✅ 완료 / 🔴 오류
  - 하단: 실시간 로그 스트림 (선택적 펼치기)
  - "작업 취소" 버튼
- **이동**: 모든 에이전트 완료 → "결과물 보기" 버튼 활성화 → /tasks/:id/results

## 7. 결과물 미리보기 (/tasks/:id/results)

- **진입**: 모니터링 완료 후 클릭, 작업 이력에서 클릭
- **요소**:
  - 탭: 결과물 유형별 (블로그 / SNS / 뉴스레터 등)
  - 각 탭 내용:
    - 텍스트 콘텐츠 렌더링
    - 파일 미리보기 (이미지, PDF)
  - 수정 요청 입력: "이 부분을 수정해줘" 텍스트 입력
  - "수정 요청" 버튼 → 재생성 → 모니터링
  - "다운로드" 버튼 (개별/전체)
  - 결과 메타데이터: 생성 시간, 사용 모델, 품질 점수
- **이동**:
  - "수정 요청" → /tasks/:newId/monitor
  - "홈으로" → /dashboard

## 8. 팀 생성 (/teams/new)

- **진입**: 홈 → "새 팀 만들기"
- **요소**:
  - Step 1: 템플릿 선택
    - 카드 그리드: 마케팅, 재무, 전략기획, 교육, 이커머스 등
    - 각 카드: 아이콘, 이름, 설명, 기본 에이전트 수
  - Step 2: 커스터마이즈
    - 팀 이름/설명 입력
    - 에이전트 목록 (추가/삭제/수정 가능)
    - 각 에이전트: 이름, 역할, 모델 선택, 프롬프트 편집
  - Step 3: 확인
    - 최종 팀 구성 요약
    - "팀 생성" 버튼
- **이동**: 생성 완료 → /dashboard

## 9. 작업 이력 (/tasks/history)

- **진입**: 사이드바 "작업 이력"
- **요소**:
  - 필터: 팀별, 날짜 범위, 상태별
  - 작업 목록 테이블:
    - 날짜, 팀 이름, 작업 유형, 상태, 소요 시간
  - 페이지네이션
- **이동**: 작업 클릭 → /tasks/:id/results

## 10. 설정 (/settings)

- **진입**: 사이드바 "설정"
- **요소**:
  - 프로필 섹션: 이름, 이메일 수정
  - API 키 관리: Claude API 키 입력/수정
  - 구독 관리: 현재 플랜, 사용량, 업그레이드
  - 알림 설정: 작업 완료 알림 ON/OFF
  - 데이터 관리: 작업 이력 내보내기/삭제
